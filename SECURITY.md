# Security

Report vulnerabilities to the address in [site/security.html](site/security.html) and in `.well-known/security.txt` of a published site (set `CONTACT_EMAIL` when building). Please include steps to reproduce and give a reasonable time to fix before publishing.

The hardening notes, what is stored, and how to erase it live on the site:

- Privacy and retention: `site/privacy.html`
- Security measures: `site/security.html`
